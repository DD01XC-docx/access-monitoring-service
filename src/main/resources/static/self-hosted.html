Install Seerlogg Self-Hosted

Run Seerlogg on your own server. It is easy to set up using Docker and gives you full control over your private security data.

✓ Open Source ✓ Docker Support ✓ Fast Setup ✓ Private

System Requirements

🖥️

Hardware

4 CPU Cores
8GB RAM minimum
50GB Disk Space
Linux preferred

🐳

Software

Docker Engine 20.10+
Docker Compose v2
Modern Browser
Internet Access

💾

Database

PostgreSQL 13+
Redis 6.0+
Automated Migrations
Easy Backups

How to Install

1

Clone Repository

First, you need to download the source code from GitHub.

git clone https://github.com/DD01XC-docx/access-monitoring-service.git
cd access-monitoring-service
2

Setup Env

Copy the example environment file and add your own keys.

cp .env.example .env
nano .env
3

Run Docker

Use Docker Compose to start all the containers at once.

docker-compose up -d
4

Final Setup

Run the application jar to finish the database setup.

docker-compose exec app java -jar seerlogg.jar --spring.profiles.active=prod

Getting stuck?

Check our documentation or reach out to the community for help with your deployment.
